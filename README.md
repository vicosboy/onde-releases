# Onde — téléchargements

Ce dépôt public contient uniquement les installateurs signés, leurs signatures et le manifeste
`latest.json` utilisé par la mise à jour automatique de l’application Onde.

Le code source reste privé dans `vicosboy/onde`, comme pour REAMIX et Pandaw. Ne téléchargez Onde
que depuis la section **Releases** de ce dépôt.

Aucune donnée musicale, aucun catalogue et aucune information d’utilisateur ne sont hébergés ici.
